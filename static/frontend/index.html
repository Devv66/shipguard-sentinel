Model Context Protocol (MCP) Server Integration rovo:mcp Module

ShipGuard exposes an MCP server conforming to JSON-RPC 2.0. External AI IDEs like Cursor, Claude Code, and Windsurf can query Jira release risks and Teamwork Graph dependencies straight from the developer terminal.

Exposed MCP Tools:
  • calculate_blast_radius: Computes 0-100 risk score and verification receipts
  • assess_release_readiness: Audits all issues in a FixVersion
  • query_teamwork_graph: Returns raw Cypher traversal graph
  • scan_context_gaps: Identifies unreviewed ADRs and out-of-office owners

Atlassian Teamwork Graph (TWG) Cypher Traversal TWG API & Cypher

ShipGuard uses native Cypher queries executed via requestTeamworkGraph to discover non-obvious blast radius paths:

// ShipGuard Teamwork Graph Cypher Query MATCH (issue:JiraIssue {key: 'PROJ-1042'}) OPTIONAL MATCH (issue)-[:DOCUMENTS|DESCRIBES]->(doc:ConfluencePage) OPTIONAL MATCH (issue)-[:DEPENDS_ON]->(service:ServiceNode) OPTIONAL MATCH (issue)-[:HAS_PR]->(pr:PullRequest) OPTIONAL MATCH (issue)-[:BLOCKS|DEPENDS_ON]->(blocked:JiraIssue) RETURN issue, collect(DISTINCT doc) as documentation, collect(DISTINCT service) as downstreamServices, collect(DISTINCT pr) as pullRequests, collect(DISTINCT blocked) as blockers
